# 📚 Algoritmos Clássicos

Um repositório dedicado à implementação de **algoritmos clássicos** da Ciência da Computação para estudo, prática e consulta.

O objetivo é reunir diferentes algoritmos e técnicas fundamentais, como busca, ordenação, divisão e conquista, árvores, grafos e muito mais.

-  Linguagens diferentes para o mesmo algorítimo



## 🧠 Algoritmos

* 🔎 Binary Search
* ✂️ Dividir e conquistar
* ⚡ Quicksort
* 🔢 Algoritmos de Ordenação
* 🌳 Algoritmos em Árvores
* 🔗 Algoritmos em Grafos
* ... 

## 🎯 Objetivo

Este repositório foi criado como uma coleção de algoritmos clássicos, servindo como material de estudo e referência para mim mesmo, mas fique a vontade para consultar.
